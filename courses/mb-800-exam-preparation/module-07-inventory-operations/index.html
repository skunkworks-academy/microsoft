Productive navigation, analysis and inventory operations

By the end, you can

  • Distinguish personalization, profile customization and extension design; inspect pages and find related entries.
  • Apply/save filters, use Edit in Excel and configure data analysis mode with appropriate permissions.
  • Process inventory receipts/shipments, transfers, adjustments, counts, reclassification and item cost adjustment.

Choose the right level of user-interface change

Personalization adapts an individual user’s workspace, such as moving a field or hiding an action. Profile customization provides an agreed workspace for users assigned that role. Extension design changes application objects and behaviour through the supported development model. A requirement to move one user’s field should not automatically become a development project. A requirement for a new validated business rule is not satisfied by hiding a field.

Use Tell Me to locate pages and actions, then inspect the relevant page when identifying the underlying table or extension. Page inspection helps distinguish similar captions and diagnose where a field comes from. It is a diagnostic tool, not permission to modify posted table data. From documents, follow related entries or Find Entries to trace postings. Keep the document number, posting date and transaction references together so that a learner can navigate from the business event to its accounting evidence.

Filtering and analysis answer explicit questions

Northstar wants open customer invoices for a defined month and a region. Apply a posting-date range and the relevant dimension or other supported filter, then check which entries remain. Multiple field filters generally narrow to records meeting all those field conditions. Within one field, an OR expression can select alternatives. A saved view preserves a useful working selection; it does not change the user’s effective security permissions.

Use unambiguous dates matching the environment’s regional input format. In a document-number field, a range such as INV100..INV120 follows the field’s sorting/format behaviour, so verify the displayed records rather than assuming every numeric-looking code is a number. Remove stale filters before deciding data is missing. FlowFilters used for totals can affect calculated balances without being the same as filtering the visible underlying rows.

Data analysis mode provides grouping, pivot-style summaries and saved analysis tabs on supported lists. Start with a defined question, choose fields and aggregations, and reconcile a sample total to source entries. A count of rows and a sum of amounts are different measures. Do not sum both invoice headers and their lines as though they were independent revenue. Analysis assists diagnosis; it does not post corrections.

On supported current versions, analysis mode requires the applicable data-analysis execution permission. A developer can also disable the capability on a specific page. Diagnose a missing analysis toggle by checking page support, application version and permissions before assuming it is a browser fault.

Spreadsheet editing is a controlled write operation

Open in Excel provides exported data for analysis. Edit in Excel uses the supported add-in experience to publish eligible changes back, subject to permissions and validation. A downloaded workbook is not proof that changes were written to Business Central. Use a small synthetic set, retain record keys, change an allowed field and publish, then refresh the application to verify the result.

Check errors before retrying a bulk update. If one row fails validation, repeating the whole exercise without understanding the error can create unintended changes. Avoid bulk-changing posting groups, bank details or critical master data without a reviewed plan. Never use this learning exercise to mass-update production or export real personal data into a public repository.

Record the physical event with the right inventory transaction

An item journal can record positive and negative adjustments under an authorised inventory process. A transfer moves stock between locations and can model in-transit handling when configured. A reclassification changes supported inventory attributes, such as location, bin, variant or tracking context, according to the applicable process. A physical inventory journal/order supports counting and posting verified differences. These are not interchangeable shortcuts.

Example: the system shows fifty units at location MAIN. A controlled count finds forty-seven. The investigated shortage is three, so the approved count difference is a negative three. Do not post forty-seven as a new positive receipt; that would inflate stock to ninety-seven. If the three missing units were actually transferred to BRANCH, investigate the unrecorded transfer instead of writing them off. Count timing matters: freeze or control movements during the count, or reconcile the movement cut-off explicitly.

Close the loop from quantity to adjusted cost

After receipt or shipment, inspect the signed item ledger quantity, location, variant and remaining quantity. Then inspect value entries. A late supplier invoice or item charge can change the final cost assigned to items already sold. Cost adjustment propagates applicable cost changes to related outbound entries; posting inventory cost to G/L updates the accounting records. These processes are distinct and may run automatically or through controlled batch jobs.

If quantity agrees but the inventory G/L balance differs, investigate unadjusted or unposted costs, expected-versus-actual amounts, posting dates and setup before entering a quantity adjustment. A quantity journal cannot correctly repair an accounting timing difference. Reconcile a narrow item/date sample first, then broaden the investigation after the causal chain is understood. Preserve the original transaction and adjustment evidence.

Sandbox lab: Count, trace and explain one discrepancy

Use synthetic records in your authorised sandbox. Record the company and work date before posting. Never run this exercise in a customer’s production company.

  1. Personalize a supported list for one test user, then explain how profile customization and extension design differ.
  2. Apply and save a date/status view. Clear it, reload it and reconcile five sample records to the expected filter conditions.
  3. Create a data-analysis tab grouped by a meaningful field and verify a small total manually. Inspect the page/table origin.
  4. Where available, use Edit in Excel on two harmless synthetic master records. Publish an allowed change and verify it in the application.
  5. In a disposable company with authorised stock, prepare a count from fifty to forty-seven. Explain why the adjustment is minus three.
  6. Demonstrate or preview a location transfer and reclassification. Trace an item’s ledger, value entries and cost-posting state.

Expected observations

  • The saved view returns the intended records without being described as a security boundary.
  • The Excel change is verified after publication, or an actual availability/permission blocker is recorded.
  • The count’s approved difference is minus three and its valuation impact is explained separately.

Evidence to retain

  • Filter definition and sample records
  • Analysis total reconciliation
  • Spreadsheet publish result or precise blocker
  • Count/transfer/reclassification decision and ledger trace

Cleanup

Restore personalizations, remove temporary analysis tabs if desired, delete unposted test journals and reverse posted training changes only through approved processes. Remove synthetic exported workbooks from shared devices.

Common pitfalls

  • Treating a saved view or hidden field as access control.
  • Using Open in Excel as though it had published changes.
  • Posting counted quantity instead of the difference, or using a quantity adjustment to fix cost timing.

Check your understanding

1. The system says fifty units and the verified count is forty-seven. What is the quantity difference?

Minus three.

Posting forty-seven as a positive adjustment would add stock instead of recording the shortage.

2. Quantity is correct, value entries are correct, but inventory G/L is behind. What should be inspected?

Inventory cost posting status, dates and setup.

A quantity adjustment would target the wrong layer and distort stock.

3. Which change affects only an individual workspace: personalization, profile customization or extension development?

Personalization.

Profile changes serve a role; an extension changes application design or behaviour.
